Le moteur Equicord conserve ses API. PulseCord ajoute une identité, des réglages et un parcours d'installation local.

Ce dépôt contient le code et les commandes de compilation. Les binaires locaux ne sont pas signés. Aucune release publique PulseCord n'est encore publiée.

Ouvrir les instructions

Compiler le mod

corepack pnpm install --frozen-lockfile
node scripts/prepare.mjs
corepack pnpm --dir upstream/equicord install --frozen-lockfile
corepack pnpm build
corepack pnpm typecheck
corepack pnpm test
corepack pnpm package:installer

Node.js 22+, Corepack et Git. Compilez sur l'OS cible. Windows est la plateforme testée dans ce dépôt ; macOS et Linux restent à valider.
