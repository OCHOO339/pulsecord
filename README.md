# PulseCord

PulseCord is an independent Discord modification based on Equicord and Vencord.

Download the installer and the complete corresponding source from [Releases](https://github.com/OCHOO339/pulsecord/releases/latest).

The client verifies official update packages with the embedded Ed25519 public key.

GPL-3.0-or-later. Original author credits and licenses are included in the source archive.
